# Shifa Khanum — Personal Portfolio

A responsive single-page portfolio using a forest-green, ivory and muted-gold professional colour palette.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `shifakhanum2005.github.io`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. After GitHub Pages finishes publishing, your site should be available at `https://shifakhanum2005.github.io/`.
